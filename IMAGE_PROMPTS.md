## Note
Save each generated file with the same filename/path the site already expects
(listed above) so no code changes are required. Prefer 4:5 (1200×1500) for
products, 16:10 for brand cards, 21:9 for visit banner, 4:3/3:4 for hero
triptych/moods. Use PNG/WEBP if your generator can't output AVIF, then convert
with ffmpeg (`ffmpeg -i in.png out.avif`).
